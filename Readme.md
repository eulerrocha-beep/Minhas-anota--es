# Minhas Anotações de Aulas e Estudos

Bem-vindo ao meu repositório de anotações! 📚

Este repositório contém todas as minhas anotações, exercícios e desafios que estou desenvolvendo durante meus estudos de desenvolvimento web e programação.

## 📖 Conteúdo

O repositório está organizado nos seguintes diretórios:

### 🎨 CSS
Anotações sobre CSS, incluindo:
- Seletores e Combinadores
- Box Model (Margin, Padding, Box-Size)
- Altura e Largura

### 💅 Estilizações Básicas com CSS
Estudos aprofundados sobre CSS com os seguintes tópicos:
- **Bordas** - Propriedades de borda, estilos e efeitos
- **Cores** - Diferentes formas de definir cores (RGB, HEX, HSL)
- **Fontes** - Personalização de tipografia (@font-face, font-weight, etc)
- **Fundo dos Elementos** - Background, imagens de fundo e efeitos
- **Imagem** - Object-fit, Object-position
- **Sombras** - Efeitos de sombra em elementos
- **Textos** - Espaçamento, alinhamento, transformação de texto

### 🌐 HTML Início
Anotações básicas de HTML:
- Elementos semânticos
- Formulários
- Tabelas
- Embeds e Iframes
- Tags de mídia (vídeo, imagem)

### 🏗️ HTML Parte 2
HTML avançado com foco em:
- Semântica HTML
- Acessibilidade
- Elementos estruturais modernos
- Web Scraping

### 💻 JavaScript
Fundamentos de JavaScript incluindo:
- Variáveis
- Estruturas de Condicionais
- Estruturas de Repetição
- Switch/Case
- Vetores e Arrays

### 🎯 Desafios
Exercícios e desafios de programação para consolidar o aprendizado.

## 🎓 Objetivo

Este repositório serve como um portfólio de aprendizado, onde documento todo o meu progresso em desenvolvimento web, desde conceitos básicos até tópicos mais avançados.

## 📝 Notas

As anotações estão em português e foram criadas conforme estudo dos respectivos tópicos.
