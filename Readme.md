# 📚 Minhas Anotações de Aulas e Estudos

Bem-vindo ao meu repositório de anotações! Este é um espaço dedicado a documentar minha jornada de aprendizado em **desenvolvimento web**.
As anotações são de cursos que estou realizando / todos comentarios explicativos foram feitos com IA do proprio vscode para meu melhor entendimento
quando for consultar algo

> Cada arquivo contém anotações detalhadas, comentários explicativos e exemplos práticos para facilitar o entendimento quando consultar no futuro.

## � Estrutura do Repositório

Os arquivos estão organizados de forma **linear e progressiva**, começando pelos fundamentos até conceitos mais avançados.

### 01 - JavaScript Fundamentos
Aprenda os conceitos básicos de JavaScript:
- **Variáveis** - `let`, `const`, `var`
- **Estruturas Condicionais** - `if`, `else`, `switch`
- **Estruturas de Repetição** - `for`, `while`, `do...while`
- **Funções** - Declaração, arrow functions, callbacks
- **Objetos** - Propriedades e métodos
- **Classes** - Orientação a objetos em JS
- **Arrays** - Manipulação com `map()`, `filter()`, `reduce()`, `forEach()`, `join()`
- **Importação** - Módulos e imports

### 02 - JavaScript Avançado
Tópicos mais complexos de JavaScript:
- Closures
- Promises e Async/Await
- Destructuring
- Spread operator
- E muito mais!

### 03 - HTML Fundamentos
Aprenda HTML desde o início:
- Estrutura básica
- Formulários
- Tabelas
- Embeds e Iframes
- Tags semânticas básicas
- Inputs e validação

### 04 - HTML Avançado
HTML mais aprofundado:
- **Semântica HTML5** - `header`, `footer`, `nav`, `main`, `article`, `section`
- **Acessibilidade** - ARIA, atributos de acessibilidade
- **Web Scraping** - Conceitos básicos
- **Elementos avançados** - `figure`, `picture`, blockquote

### 05 - CSS Fundamentos
Base do CSS:
- **Seletores** - Por tag, classe, ID, atributo, universal
- **Combinadores** - Descendente, filho, irmão
- **Box Model** - Margin, Padding, Border, Box-sizing
- **Altura e Largura** - Width, Height, Min/Max
- **Depuração** - Developer Tools

### 06 - CSS Estilos Básicos
Personalização visual:
- **Cores** - RGB, HEX, HSL, Cores predefinidas
- **Fontes** - Tipografia, font-weight, font-size
- **Bordas** - Estilos, tamanho, imagens em bordas
- **Fundo dos Elementos** - Background, gradientes
- **Sombras** - Box-shadow, Text-shadow
- **Textos** - Text-overflow, transformações

### 07 - CSS Flexbox
Layout flexível com Flexbox:
- **Conceitos** - Main axis, cross axis
- **Flex-direction** - Linha, coluna, reverso
- **Justify-content** - Alinhamento do eixo principal
- **Align-items** - Alinhamento do eixo transversal
- **Flex-wrap** - Quebra de linhas
- **Gap** - Espaçamento entre itens
- **Order** - Ordenação de itens
- **Flex-basis, Flex-grow, Flex-shrink** - Dimensionamento

### 08 - CSS Grid
Layout em grade:
- **Conceitos** - Linhas, colunas, áreas
- **Grid Template** - Definição de colunas/linhas
- **Áreas** - Grid areas
- **Alinhamento** - Justify, Align
- **Minmax** - Tamanho mínimo/máximo
- **Implícito vs Explícito**

### 09 - CSS Posicionamento
Posicionamento de elementos:
- `position: static` (padrão)
- `position: relative`
- `position: absolute`
- `position: fixed`
- `position: sticky`
- Z-index

### 10 - CSS Display
Propriedade display:
- `display: block`
- `display: inline`
- `display: inline-block`
- `display: flex`
- `display: grid`
- `display: none`

### 11 - CSS Unidades de Medida
Entenda as unidades:
- **Absolutas** - `px`, `cm`, `mm`
- **Relativas** - `em`, `rem`, `%`, `vw`, `vh`
- **Quando usar cada uma**

### 12 - CSS Responsividade
Design responsivo:
- **Media queries**
- **Mobile first**
- **Breakpoints**
- **Viewport**

### 13 - CSS Prática Grid
Exercícios práticos com CSS Grid

### 14 - JSON
Aprenda sobre JSON:
- Sintaxe
- Tipos de dados
- Parsing
- Stringifying

### 15 - Desafios
Desafios e exercícios práticos para consolidar o aprendizado!
